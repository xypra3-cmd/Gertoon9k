# Нууцлалын бодлого

> **Төсөл.** Хүний хувийн мэдээлэл хамгаалах тухай хуулийн дагуу хуульчаар хянуулна.

## 1. Бид ямар мэдээлэл цуглуулдаг вэ

| Мэдээлэл                            | Зорилго                                     | Хадгалах хугацаа                   |
| ----------------------------------- | ------------------------------------------- | ---------------------------------- |
| Нэр, имэйл, утас (бүртгэл)          | Бүртгэл, нэвтрэлт, мэдэгдэл                 | Бүртгэл устгах хүртэл              |
| Картын мэдээлэл                     | Таны нийтийн картыг харуулах                | Бүртгэл устгах хүртэл              |
| Зочны үлдээсэн мэдээлэл             | Картын эзэнд дамжуулах (зөвхөн зөвшөөрлөөр) | Эзэмшигч эсвэл зочин устгах хүртэл |
| Нэргүй статистик (hash)             | Нээлт, давхардаагүй зочин тоолох            | 13 сар                             |
| Төлбөр (invoice, гүйлгээний дугаар) | Төлбөр баталгаажуулах                       | Татварын хуулийн хугацаа           |

## 2. Бид юуг цуглуулдаггүй

- Зочдын **IP хаягийг хадгалдаггүй.** Давхардаагүй зочныг тоолохдоо өдөр бүр солигддог salt-тай нэг талын hash ашиглана.
- Банкны картын дугаар хадгалдаггүй (төлбөрийг QPay боловсруулна).

## 3. Нэрээр харагдах

Нэвтэрсэн хэрэглэгч «Миний нэрийг картын эзэнд харуулахыг зөвшөөрөх» тохиргоог асаасан тохиолдолд л картын эзэн түүний нэрийг харна.

## 4. Хуваалцах

Таны мэдээллийг худалдахгүй. Үйлчилгээ үзүүлэгчид: Supabase (өгөгдлийн сан), QPay (төлбөр), Cloudflare (spam хамгаалалт), имэйл илгээх үйлчилгээ.

## 5. Таны эрх

Мэдээллээ үзэх, засах, экспортлох (CSV, .vcf), бүртгэлээ бүрэн устгах эрхтэй.
