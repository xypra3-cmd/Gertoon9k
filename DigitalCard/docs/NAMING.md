# Брэнд нэрийн сонголт («Digital Card»-аас илүү анхаарал татах)

**Яагаад солих вэ:** «Digital Card» нь ерөнхий нэр — домэйн, store-д мянга мянган ижил нэртэй апп байна, барааны тэмдгээр хамгаалагдахгүй, монгол хэрэглэгчийн сэтгэлд хүрэхгүй.
**Шалгуур:** богино (≤ 7 үсэг), монголоор утгатай, латинаар бичихэд хялбар, ойртуулж/танилцаж/тэмдэг үлдээх санаатай, .mn ба .com-д авах боломжтой, store-д ижил нэртэй апп байхгүй.

|---|---|---|---|

## 2. Санал болгох бүтэц

**Temdeg** — *ухаалаг нэрийн хуудас*
- Домэйн: `temdeg.mn` (үндсэн), `temdeg.app` эсвэл `gettemdeg.com` (.com эзэнтэй бол)
- Нийтийн карт: `temdeg.mn/c/saraa` → цаашид `temdeg.mn/saraa`
- Уриа: «Тэмдгээ үлдээ — уулзсан хүн бүрээ марталгүй»
- Store-д: «Temdeg — Цахим нэрийн хуудас» (хайлтын түлхүүр үг нэрэнд багтана)
- Ойртуулж солилцох функцэд: «Тэмдэг солилцох» — нэртэй шууд холбогдоно

**Нөөц:** Kartaa — «Картаа өг» гэсэн ярианы үйлдэлтэй; маркетингийн хэллэг: «Картаа өгөөд л болоо».

## 3. Код дахь нэрийг солих (шийдсэний дараа)

Нэр нь i18n (`app.name`), `mobile/app.config.ts` (name, slug, bundle id), `index.html` title, имэйлийн загвар, docs-д байна. Bundle id (`mn.digitalcard.app`) store-д гарсны дараа солигдохгүй тул **store-д илгээхээс өмнө** шийднэ.
