# Аюулгүй байдлын зөрчлийн үед авах арга хэмжээ (runbook)

Хувийн мэдээлэл хамгаалах тухай хууль (2022) нь мэдээлэл хариуцагчаас аюулгүй байдлын зөрчил, кибер халдлагыг **бүртгэж, нэн даруй арга хэмжээ авахыг** шаарддаг. Энэ баримт тэр үйл ажиллагааг тодорхойлно.

## 2. Алхам (цаг нь илрүүлснээс тоолно)
1. **0–1 цаг — тогтоох.** Нөлөөлсөн түлхүүрийг солих (Supabase service role, JWT secret, QPay, Anthropic, Resend, Wallet сертификат — `supabase secrets set`). Шаардлагатай бол Edge Function-ийг унтраах, Auth-д бүх session-ыг цуцлах.
2. **1–4 цаг — үнэлэх.** Ямар мэдээлэл (бүртгэл, карт, харилцагч, тэмдэглэл, төлбөр), хэдэн хэрэглэгч, ямар хугацаанд. Эх сурвалж: Supabase logs, Edge Function `logEvent` (IP, токен бичигддэггүй), audit_log хүснэгт.
3. **4–24 цаг — бүртгэх.** Доорх бүртгэлд нэмэх. Хуулийн зөвлөгөө авах.
4. **≤ 72 цаг — мэдэгдэх.** Эрсдэлтэй бол нөлөөлсөн хэрэглэгчдэд имэйлээр (юу болсон, юу хийх хэрэгтэй), шаардлагатай бол эрх бүхий байгууллагад (Хүний эрхийн үндэсний комисс / Цахим хөгжлийн яам) мэдэгдэх. 72 цаг нь GDPR-ийн жишиг; Монголын журмын хугацааг хуульчаар баталгаажуулна ✱.
5. **Дараа нь — сургамж.** Шалтгааныг засах migration/тест (pgTAP эсвэл API), `docs/SECURITY_AUDIT.md`-д тэмдэглэх.
